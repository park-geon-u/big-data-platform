# AI 업무 비서 웹앱

여러 사용자가 쓰는 AI 업무 비서입니다. 사용자마다 독립된 AI 대화, 파일·참여자가 있는 프로젝트, 권한 기반 파일 저장소를 제공합니다.

## 실행

```bash
npm install
npm start                # http://localhost:3000
npm test                 # 권한·파일 읽기 테스트
```

## AI 연결 (사용자마다 자기 키)

각 사용자가 왼쪽 아래 **⚙ 내 AI 설정**에서 자기 API 키를 넣습니다. 파일을 고칠 필요가 없습니다.

| AI | 키 발급 | 키 모양 |
|---|---|---|
| Claude (Anthropic) | console.anthropic.com/settings/keys | `sk-ant-...` |
| GPT (OpenAI) | platform.openai.com/api-keys | `sk-...` |
| Gemini (Google) | aistudio.google.com/apikey | `AIza...` |

- 키를 저장하기 전에 그 회사 서버에서 모델 목록을 받아 와 키가 맞는지 확인하고, 받아 온 목록에서 모델을 고를 수 있습니다.
- 키는 `data/secret.key`(또는 `APP_SECRET` 환경 변수)로 AES-256-GCM 암호화해 DB 에 저장합니다. 화면에는 끝 4자리만 보이고, 다른 사용자는 볼 수 없습니다.
- 대화 화면 위쪽에서 질문할 AI 를 바로 바꿀 수 있고, 답변마다 어떤 모델이 답했는지 표시합니다.
- 공유 스레드에서도 **질문한 사람 본인의 키**로 답합니다.
- 키가 없으면 데모 응답으로 동작합니다.
- 파일은 세 AI 모두에 전달됩니다 (텍스트는 추출본, 이미지와 스캔 PDF 는 원본).

## 구현 범위

| 단계 | 내용 | 상태 |
|---|---|---|
| 1차 | 로그인, 개인 AI 대화, 프로젝트, 파일 저장 | ✅ |
| 2차 | 사용자 초대, 파일 공유와 권한 | DB·권한 로직 준비됨, 화면/API 예정 |
| 3차 | 공유 AI 스레드, AI 문서 생성 | 권한 로직 준비됨, 화면/API 예정 |

## AI 가 읽을 수 있는 파일

| 형식 | 처리 방식 |
|---|---|
| PDF | 텍스트 추출 (한글 포함). 스캔본처럼 글자가 없으면 PDF 원본을 Claude 에 그대로 전달 |
| Word `.docx` | 본문 텍스트 추출 |
| Excel `.xlsx` | 시트별 표를 탭 구분 텍스트로 변환 |
| PowerPoint `.pptx` | 슬라이드별 텍스트 + 발표자 노트 |
| 한글 `.hwpx` | 본문 텍스트 추출 |
| 이미지 PNG·JPG·GIF·WEBP | Claude 비전 입력으로 전달 |
| HTML | 태그를 제거한 본문 |
| 텍스트·CSV·JSON·코드 등 | 그대로 (UTF-8, 깨지면 CP949/EUC-KR 로 재시도) |
| 구형 `.hwp` `.doc` `.xls` `.ppt` | 미지원 안내 (새 형식으로 저장 권장) |

업로드할 때 한 번 추출해 DB 에 저장하고, 질문할 때 대화에 붙은 파일을 Claude 에 함께 보냅니다.

## 권한 원칙

모든 데이터 접근과 AI 호출은 **서버에서 세션의 사용자 ID 기준으로** 검사합니다 (`src/authz.js`). 화면에서 버튼을 숨기는 것과 상관없이 API 를 직접 호출해도 같은 검사를 거치며, 권한이 없으면 존재 여부도 알리지 않도록 404 를 돌려줍니다.

- 개인 AI 대화: 본인만 접근
- 프로젝트: 멤버만 접근. 멤버라도 다른 사람의 스레드·비공개 파일은 자동으로 보이지 않음
- 스레드 권한: 접근 불가 / 읽기(열람만) / 참여(메시지 작성·AI 질문)
- 파일: 기본 "나만 보기", 업로더가 "프로젝트 공개"로 바꿀 수 있음
- 공유 스레드에서 AI 는 그 스레드 참여자 **모두가** 볼 수 있는 파일만 사용
- 권한이 회수되면 다음 요청부터 바로 차단

## 구조

```
src/
  server.js      실행 진입점
  app.js         API 라우트
  authz.js       권한 검사 (모든 판단이 여기 모임)
  db.js          SQLite 스키마
  fileReader.js  파일 형식별 내용 추출
  ai.js          Claude·GPT·Gemini 호출 (키가 없으면 데모 응답)
  settings.js    사용자별 API 키 암호화 저장, 쓰는 AI·모델
public/          화면 (빌드 없는 순수 JS)
test/            권한·파일 읽기 통합 테스트
```
